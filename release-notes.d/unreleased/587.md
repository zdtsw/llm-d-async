Request transforms can implement the optional `transform.ContextTransform` interface to receive the attempt context, dispatch URL, and original request deadline. The context is bounded by the earlier of the request deadline and `--request-timeout`, and is cancelled on shutdown or request cancellation. Retryable transform errors use backoff; a timeout at the request's own deadline reports `DEADLINE_EXCEEDED`, while a per-attempt timeout with time remaining is retried. Shutdown re-enqueues the request, and request cancellation reports `CANCELLED`. Transform error results, spans and retry logs omit the raw cause wrapped by an `api.ClientError`. `transform.Chain.Apply` is deprecated but remains available for compatibility with callers.
